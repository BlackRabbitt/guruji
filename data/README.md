# data/ — private, gitignored

This directory holds your personal mentoring profile (`profile.md`) and your
running notes history (`notes/`). It is intentionally excluded from version
control by the `.gitignore` at the root of this skill (everything under `data/`
is ignored except this README).

Do not remove the `.gitignore` rule and do not commit real contents of this
directory to any shared/public repository — it can contain sensitive details
about your career, employer, and specific incidents/decisions.

If you're publishing this skill (e.g. to a public GitHub repo), this directory
should always show up empty aside from this file and the placeholder index.
